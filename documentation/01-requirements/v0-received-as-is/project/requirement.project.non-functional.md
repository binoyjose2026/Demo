# Non-Functional Requirements — Project Execution (AI-Assisted Engineering Process)

**Version:** v1
**Status:** Draft — derived from client-provided assessment brief
**Source:** client-provided project assessment document
**Scope note:** This document defines quality attributes, constraints, and governance principles for *how the project must be executed*. For quality attributes of the URL shortener application itself, see `../app/requirement.app.non-functional.md`.

## 1. Purpose

This document defines the non-functional requirements for executing the project, as requested by client.

## 2. Timeline Constraint

- **NFR-01:** The project must be completed and improved within 2-3 days.

## 3. AI Usage Governance & Oversight

- **NFR-02:** Traceability — all AI-generated/edited/rejected content must be recorded, with rationale.
- **NFR-03:** Quality Gates — analysis, linting, tests, security, and performance checks must be applied to AI-assisted output.
- **NFR-04:** Secure AI usage must be enforced.
- **NFR-05:** Human sign-off is required for high-impact changes.
- **NFR-06:** The engineer retains explicit ownership of correctness, maintainability, and production readiness of all output.
- **NFR-07:** Controlled oversight — the engineer leads execution and approves all outputs; AI assists within individual tasks only, not as an autonomous orchestrator.

## 4. Code & Process Quality

- **NFR-08:** Code must be production-quality, modular, testable, reliable, secure, and scalable (core engineering principles).
- **NFR-09:** Design must be clean and maintainable.
- **NFR-10:** Change management must be safe.

## 5. Output Quality Bar / Acceptance Criteria

- **NFR-11:** AI-assisted engineering execution must be effective and demonstrable.
- **NFR-12:** Architecture and system design must be of high quality.
- **NFR-13:** Decomposition and execution must be sufficiently deep and rigorous.
- **NFR-14:** Outputs must be realistic and of high quality, not superficial.
- **NFR-15:** Validation and risk management must be rigorous.
- **NFR-16:** Decisions must be clear and defensible, with documented reasoning.
- **NFR-17:** Engineering judgment must be demonstrated throughout.

## 6. Guiding Principle

- **NFR-18:** The work must be treated as production-grade engineering: strong design fundamentals, effective use of AI as an accelerator, clear output ownership, and defensible reasoning. AI assists the engineer within tasks; the engineer owns execution and quality.
